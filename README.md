# Rights-labelled Synthetic Conformance Corpus and Explorer

An explicitly synthetic, rights-labelled reference corpus and two useful functions: `validateCorpus` verifies structure and rights labels; `queryCorpus` filters deterministic local copies by text, stage, locale, media type, tags and rights status.
