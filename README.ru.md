# Синтетический conformance-корпус с маркировкой прав и explorer

Явно синтетический справочный корпус и две функции: `validateCorpus` проверяет структуру и маркировку прав, а `queryCorpus` детерминированно фильтрует локальные копии по тексту, этапу, языку, типу медиа, тегам и статусу прав.
